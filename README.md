# Sistema de Gerenciamento Bancário

Este repositório contém um sistema simples de gerenciamento bancário, desenvolvido como parte de um projeto acadêmico. O objetivo é simular operações bancárias básicas, como criação de contas, depósitos, saques e transferências.

---

## 📋 Funcionalidades
- 🏦 Cadastro de clientes e contas bancárias.
- 💸 Depósitos, saques e transferências entre contas.
- 📄 Consulta de saldo e histórico de transações.
- 🔒 Implementação de regras de segurança para operações bancárias.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido utilizando:
- **Java** como linguagem principal.
- **Orientação a Objetos (OOP)** para organização do código.
- **Bibliotecas padrão do Java** para operações básicas.
